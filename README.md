# Yaduvanshi Transport — Animated Website

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this folder to GitHub, then import the repository into Vercel.
No environment variables are required for this first version.

## Important
The phone number and business claims in this first version are based on the supplied creatives.
Before final client delivery, confirm:
- official business name/legal name
- office address
- email
- social links
- fleet details
- GST/CIN if they want them displayed
- exact service coverage
- any claims such as "Pan India"


## Hero video
The supplied MP4 is included at:
`public/videos/yaduvanshi-transport.mp4`

It is configured to autoplay, loop, stay muted, and play inline on supported browsers.
The first supplied poster image is used as the video fallback/poster.
